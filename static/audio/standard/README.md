# Aufnahmen der Originaltexte

Vom Auftraggeber bereitgestellte MP3-Dateien, unverändert übernommen:

| Datei | Originaldatei | Seite |
| --- | --- | --- |
| `startseite.mp3` | `Startseite-normal.mp3` | `/` |
| `philosophie.mp3` | `Philosophie-normal.mp3` | `/unsere-philosophie/` |
| `unvereinbarkeitserklaerung.mp3` | `Unvereinbarkeitserklärung-normal.mp3` | `/unvereinbarkeitserklaerung/` |

Die Zuordnung zur normalen Sprachfassung steht in `data/audio.toml`.
Diese Aufnahmen werden nicht ersatzweise für Leichte Sprache abgespielt.
