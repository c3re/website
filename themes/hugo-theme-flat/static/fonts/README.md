# Local fonts

Fonts from the design reference, served locally without requests to Google Fonts.

- Noto Sans: `@fontsource-variable/noto-sans`, version 5.3.0, Latin, normal,
  variable weight 100–900.
- Space Mono: `@fontsource/space-mono`, version 5.3.0, Latin, normal,
  weights 400 and 700.

Source: https://fontsource.org/ (npm packages distributed via jsDelivr).
Both fonts are distributed under the SIL Open Font License in `OFL.txt`.
