# Local fonts

Fonts from the design reference, served locally without requests to Google Fonts.

- Noto Sans: `@fontsource-variable/noto-sans`, version 5.3.0, Latin, normal,
  variable weight 100–900.
- Space Mono: `@fontsource/space-mono`, version 5.3.0, Latin, normal,
  weights 400 and 700.

Source: https://fontsource.org/ (npm packages distributed via jsDelivr).
Both fonts are distributed under the SIL Open Font License in `OFL.txt`.

## CCC design (40C3 styleguide)

Fonts for the selectable "CCC-Design", taken from the 40C3 styleguide package
(https://events.ccc.de/congress/2026/infos/styleguide/), served locally:

- Jersey 10 (`jersey-10-latin-400-normal.woff2`), headings. SIL Open Font
  License, see `Jersey10-LICENSE.txt`. Source: github.com/scfried/soft-type-jersey
- Hack (Regular, Bold, Italic, BoldItalic as `.woff2`), body and code. MIT
  License, see `Hack-LICENSE.txt`. Source: github.com/source-foundry/Hack

The colors (`#001300`, `#ebedf0`, `#75b44b`, `#ffbc40`, …) and the design
concept are CC0 according to the styleguide.
